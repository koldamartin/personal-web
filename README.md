## 🎮 Aesthetic & Features

This website is engineered with an old-school **Charm / TUI (Terminal User Interface)** and **IDE** aesthetic inspired by [Charmbracelet](https://charm.sh) and modern terminal tools like OpenCode.

* **Split IDE Layout**: Full-width editor workspace with tabs on top (`01_profile.py`, `02_ai_models.py`, `03_websites.tsx`, `04_career.log`).
* **Integrated Terminal**: Interactive terminal console on by default at the bottom (`help`, `ai`, `websites`, `skills`, `cat resume`, `matrix`, `clear`).
* **8-bit Pixel Art**: Hand-crafted 32×32 pixel art vectors rendered with SVG `shape-rendering="crispEdges"` for razor-sharp display at any DPI.
* **Web Audio API Synth**: Native synthesized 8-bit sound effects (<kbd>S</kbd> to toggle).
* **Phosphor CRT Shader**: Toggleable retro scanline effect (<kbd>T</kbd> to toggle).
* **Keyboard Navigation**: Instant switching with keys <kbd>1</kbd> through <kbd>4</kbd>, terminal jump with <kbd>5</kbd> or <kbd>`</kbd>.

## 🛠 Local Development

```bash
# Clone the repository
git clone https://github.com/koldamartin/personal-web.git
cd personal-web

# Install dependencies
npm install

# Start background dev server
astro dev --background

# Check server status
astro dev status

# Build for production
npm run build
```
